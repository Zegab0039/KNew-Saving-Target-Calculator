## 👻 KNew STC - Saving Target Calculator

From **Key NEWledge**, the KNew STC is a simple tool designed to help people calculate their financial goals and make impossible dreams come true.

## 🚀 About the Project
This Python-based calculator was built to solve common logic challenges like interest rate compounding and variable scope.

## ✨ Features
* **Dynamic Target Calculation:** Set your goal.
* **Monthly Contributions:** Factor in how much you can realistically save each month.
* **Interest Rate Integration:** Calculates monthly growth based on annual percentage rates.
* **Clean Logic:** Built with a centralized function to ensure accuracy and performance.

## 🛠️ How to use
1. Run the script `main.py`.
2. Enter your saving target.
3. Input your monthly contribution.
4. Add the expected annual interest rate.
5. Get your result and see your "Extra" balance!
